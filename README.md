易学階梯附言。谷川順祐（竜山）の著で、易の占筮の方法（窮理・本筮式・卦象・賓主法・生卦など）を解く。明治 44 年（1911 年）に早稲田大学出版部が『漢籍国字解全書』第 3 巻に収めたもの。OCR の柱から付けた見出しが付く。
